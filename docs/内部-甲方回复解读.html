5. 这个预算能做什么

他嘴上是 C，钱包是入门价。建议对外收成下面这包，不要按 C 接。

建议承诺（约 ¥3,500–5,000）

  • 做 只换首页。PbootCMS 后台、子页路由、已有文章/PDF 不动。
  • 做 桌面：浅色或深色「空间 + 环绕卡片 + 四行可点标题 + 可跳过开场」。标题链到现有 /?me/ 等。
  • 做 手机：单独一版构图（不是缩桌面）。开场缩短或直接落版，下面用 4 个入口卡填高度，避免空白。
  • 做 先占位样板，他再插自己的词、图、链接。
  • 做 中心形象用他提供的拟我 / 照片 / 简单插画，不做影视级 3D 电影。

明确不做或另议

  • 不做 抠、仿制、商用豆包 3D 角色或成片。
  • 不做 豆包那种 20 屏滚动技能章（除非他加钱，且他自己也说了不想要）。
  • 不做 重建博客后台、重新上传全部内容。
  • 另议 全站改成和首页同一套浅色/深色（改 CSS，不动内容）：约再加一截，或放进 5000 顶格里只做配色。
  • 另议 竞赛列表封面支持视频 + 保留 PDF：他说可做可不做。
  • 另议 中英切换：标题级可以谈，全文不行。
  • 另议 自制 3D 身体 + Memoji 头的短开场片：单这一项就可能吃掉整份预算，不放进 3000。
版权：不能答应「把豆包模型抠出来、脸换成拟我」。正确说法：身体我们按「简笔 3D 男性」自己做或找免版税模型，头用他导出的 Memoji/照片；或者开场不用真人 3D，只用卡片和标题。

6. 技术怎么接，才不用让他重传内容

  1. 在现有 PbootCMS 里只改首页模板（或做一个新首页模板指过去）。
  2. 导航五项继续指向旧栏目。卡片标题用他定的四个词，href 写死到现有栏目。
  3. 开场：桌面用短视频或 CSS/Web 时间轴；手机用静帧 + 轻动效。他问「改窗口会不会重播」——会，这是正常的，可以做成「播过一次就记住」。
  4. 豆包开场看起来像实时 3D，实际是预渲染视频再切到 CSS 卡片。和他讲清楚，避免他以为 5000 能买实时角色。

7. 建议你回他的口径

姚先生你好。视频和表单我对过了，需求可以收成一句：只换 yaojunxd.com 的首页，做成豆包那种开场和可点卡片；点了进入你现在的简介、竞赛等页面。子页面内容和后台不动。

预算 3000–5000 的话，我建议先做这一包：桌面开场 + 手机单独一版 + 四个标题跳转 + 占位样板。滚动长章节按你的意思先不做。手机高度我会用四个入口卡填上，避免缩完底下空一截。

3D 角色不能直接抠豆包的模型（就算个人主页也有版权风险）。可以二选一：① 你导出拟我/照片放在画面中心，身体用我们自己做的简笔形象；② 这一期先不做人物，只做卡片和标题，观感仍然接近。你更倾向哪个？

子页面如果只要「看起来跟新首页一家」，我可以只改颜色和字体，不改排版和后台。竞赛封面改成可传视频、并保留跳转 PDF，作为附加项，首页过关后再说。

先出一版可点的首页样板给你看。你看样板再换内容。
