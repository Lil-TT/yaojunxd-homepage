2. 视频里的动画，拆开看是什么

以上截取自您提供的录屏。完整开场可概括为五段：失焦 → 角色 → 环绕 → 对焦翻牌 → 落版可滚动。

2.1 开场 25 秒：看起来像实时 3D，实际是「预渲染成片」

线上页面里，这段开场对应一条事先做好的 25 秒左右静音视频。 人物走路、挥手、说话气泡、卡片绕行、镜头推拉，都是先在三维软件里渲染成片，再嵌进网页播放。 并不是网页里实时算出来的那个人。

所以：影视级角色，是 3D 制作；网页负责播放、衔接、跳过，以及后面的可交互层。 有没有现成成片、要不要自己的 3D 人物，会直接决定项目体量。

2.2 开场播完之后：才变成「真网页」

25 秒结束后，视频淡出，同一构图切到可交互层。这一层用的是网页技术，不是再播一整条电影：

  • 空间感卡片：用网页三维透视、位移、旋转、缩放，做出环绕和轻微悬浮。
  • 循环背景：一条更短的循环视频垫在后面，保持光晕和呼吸感。
  • 景深虚化：不在焦点的卡片做模糊和透明度，模拟镜头对焦。
  • 跳过按钮：不想看开场的人可以直接落到首页。

2.3 再往下滚：整页其实是一部「用滚动当时间轴」的短片

豆包 About 在开场后还有写作 / 绘画 / 搜索 / 音乐等章节。做法是：一屏钉住，滚动不再推走画面，而是带动画进度；章节里再叠演示视频和矢量动画。整页非常长。

一句话：3D 成片和原创内容决定气质上限，滚动编排和手机性能决定难易。 前端可以做成这种感觉，但不能在没有角色、没有卡片、没有文案的情况下，凭空长得和参考一模一样。
