1. 我们先对齐一件事

您发来的视频，不是一段独立的宣传片，而是豆包 About 页开场动画的屏幕录制（约 24.9 秒，2560×1436）。 视频里的 3D 人物、环绕卡片、标题逐行出现、景深虚化，与线上页面是同一套效果。

豆包这一页在开场之后还有很长的滚动叙事（整页高度约 27,000 像素，大约 20 多个屏幕）。 您目前只给了开场 25 秒。因此报价会拆成「只做开场」和「开场 + 滚动章节 + 博客」两层，避免后期范围膨胀。

版权提醒：豆包的 3D 角色、卡片插画、文案和成片不能直接用于您的博客。 我们做的是同类型体验（气质、节奏、交互），不是 1:1 搬运。人物和卡片必须换成您自己的形象与内容。

2. 视频里的动画，拆开看是什么

以上截取自您提供的录屏。完整开场可概括为五段：失焦 → 角色 → 环绕 → 对焦翻牌 → 落版可滚动。

2.1 开场 25 秒：看起来像实时 3D，实际是「预渲染成片」

线上页面里，这段开场对应一条 1920×1080、时长 25.2 秒的静音 MP4（opening.mp4）。 人物走路、挥手、气泡「Hi 我是豆包」、卡片绕行、镜头推拉，都是先在三维软件里渲染成视频，再嵌进网页播放。 页面上没有实时 WebGL 角色，也没有 Three.js 场景在算这个人。

这对报价很关键：影视级角色不是前端写出来的，是 3D 制作成本。前端负责的是播放、衔接、跳过、和后面的可交互层。

2.2 开场播完之后：才变成「真网页」

25 秒结束后，视频淡出，同一构图切到可交互层。这一层用到的是网页技术，不是再播一整条电影：

  • CSS 三维透视：卡片用 perspective + 位移/旋转/缩放，做出环绕空间感，并带轻微悬浮。
  • 循环背景视频：一条更短的循环 MP4 垫在后面，保持光晕和呼吸感。
  • 景深虚化：不在焦点的卡片做 blur / opacity，模拟镜头对焦。
  • 跳过按钮：不想看开场的人可以直接落到首页。

2.3 再往下滚：整页其实是一部「用滚动当时间轴」的短片

豆包 About 在开场后还有写作 / 绘画 / 搜索 / 音乐等章节。实现方式是：

  • 粘滞章节（sticky）：一屏钉住，滚动不再推走画面，而是驱动动画进度。
  • 滚动驱动变换：模块的位置、缩放、旋转、模糊随滚动值变化；技能演示本身又是几条独立 MP4。
  • Lottie（矢量动画）：章节背景有大尺寸 SVG/Lottie，Safari 另做降级。
  • 前端框架：React 单页 + 工具类样式；整页高度约 27,100 px。
一句话：贵的是 3D 成片和原创内容，难的是滚动时间轴和性能。 前端可以复现这种体验，但不能在没有角色、没有卡片、没有文案的情况下「凭空长得一模一样」。
