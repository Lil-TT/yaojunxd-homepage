A. 开场氛围与时间轴 本轮已做

勾选 项目 验收要点

B. 3D 人物 本轮已做（退场缩放待下一轮）

勾选项目验收要点
□ 出场动作 idle → 挥手 / Yeah → 摊手介绍，与圆孔扩开、卡片爆出节奏大致合拍。
□ 肤色 面部与手部贴图已调暗约 20%、略偏暖，更接近亚洲人肤色。请确认是否合适。
□ 淡出时机 镜头拉远后人物逐渐淡出，卡片环落定前人已基本退干净。

C. 主卡与子卡布局 本轮已确认节点

勾选项目验收要点
□ 主卡落点 七张主卡位置、大小、倾角以你确认的最终记录为准；开场落到落点时无「闪一下」。
□ 子卡关系 子卡相对主卡的位置 / 大小 / 倾角锁定；各组子卡数量可不同（含左下竞赛组已单独确认）。
□ 层级 生长过程中子卡始终在主卡下层，不盖住主卡。
□ 爆炸同步 主卡爆炸变大变小时，子卡按同一比例跟着变。
□ 虚化同步 子卡长出到第一行字出现，主卡层与子卡层一起虚化，无明显时间差。

D. 标题与进页 本轮已做

勾选项目验收要点
□ 四行标题 个人简介 / 学科竞赛 / 科研经历 / 知识产权逐行出现，落版后可点。
□ 悬停反馈 悬停标题时对应主卡轻微推近；无变色、无下划线（按你的意见）。
□ 点击进页 点击标题：该主题一张主卡推到跟前并铺满画面 → 再进入现站对应栏目（?me / ?contest / ?science / ?ip）。
