yaojunxd.com 首页开场
样板 · 使用说明

2026年10月　·　中期样板　·　本机预览含 3D　·　未改线上网站

推荐用下面「方式 A」打开 Next 工程，可看到完整开场：3D 出场 / 挥手 / 定格、卡片环绕、四标题对焦。人物为已对齐的正式形象（实时 GLB，非开场成片）。

从 GitHub 下载

  1. 打开 https://github.com/Lil-TT/yaojunxd-homepage
  2. 点绿色 Code → Download ZIP
  3. 解压到本地文件夹

方式 A（推荐）· Next 工程

需已安装 Node.js（建议 20 及以上）。

  1. 终端进入解压后的项目根目录（能看到 package.json 的那一层）
  2. 执行：
    npm install
    npm run dev
  3. 浏览器打开终端提示的地址（一般为 http://127.0.0.1:3000）

第一次 npm install 与首次加载 3D 模型会稍慢，属正常。右下角可「跳过动画」。右上角汉堡为现站风格菜单。

方式 B · 早期静态样板（preview）

若只需看早期静态包：进入 preview 文件夹，按该目录内说明用本地服务器打开（勿直接双击 index.html）。完整中期效果以方式 A 为准。
