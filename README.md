## 怎么预览（推荐）

1. 本页右上绿色 **Code** → **Download ZIP**，解压  
2. 安装 [Node.js](https://nodejs.org/)（建议 20+）  
3. 在项目根目录执行：

```bash
npm install
npm run dev
```

4. 浏览器打开 `http://127.0.0.1:3000`（以终端提示为准）

看手机效果：把窗口拉窄到手机宽度后**再刷新一次**。
