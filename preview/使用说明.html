怎么打开

  1. 解压本包，进入 preview 文件夹。
  2. 不要直接双击 HTML（3D 和模块脚本在文件协议下会失败）。
  3. Mac：打开「终端」，输入：
    cd 解压后的目录/preview
    python3 -m http.server 8766
  4. Windows：在该文件夹地址栏输入 cmd 回车，再运行：
    python -m http.server 8766
  5. 浏览器打开 http://127.0.0.1:8766/

没有 Python 时，也可以把整个 preview 拖进 VS Code / Cursor，用 Live Server 打开 index.html。

这一版能看什么

  • 点「个人简介 / 学科竞赛 / 科研经历 / 知识产权」进入现网站对应栏目
  • 右下角「跳过动画」；播完后「重播开场」
