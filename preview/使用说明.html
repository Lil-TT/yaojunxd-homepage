yaojunxd.com 首页开场
样板 v0 · 使用说明

2026年9月22日　·　本机预览含 3D　·　不会改线上网站

请用浏览器打开首页，刷新即可看到完整开场（含 3D 角色）。这版角色是流程占位，方便你先评气质和节奏；正式形象会按你的照片做成轻量动漫 / Memoji，不会把占位角色做到 yaojunxd.com。

怎么打开（必须用本地服务器）

不要直接双击 index.html。3D 模型需要通过 http 加载，双击会看不到角色。

  1. 解压后进入带 index.html 的文件夹（有的压缩软件会多一层目录）。
  2. Mac：打开「终端」，输入：
    cd 解压后的文件夹
    python3 -m http.server 8766
  3. Windows：在该文件夹地址栏输入 cmd 回车，再运行：
    python -m http.server 8766
  4. 浏览器打开 http://127.0.0.1:8766/

没有 Python 时，把整个文件夹拖进 VS Code / Cursor，用 Live Server 打开 index.html 也可以。

第一次加载约 16MB 模型，Wi‑Fi 下等一两秒属正常。右下角可「跳过动画」，播完可「重播开场」。

这一版能看什么

  • 背景 #171717，标题蓝 #035AA6
  • 你提供的技能图：圆角、倾斜、底下高斯模糊
  • 开场：圆头像 → 3D 挥手 → 卡片散开 → 四个标题逐行对焦 → 落版可点
  • 点「个人简介 / 学科竞赛 / 科研经历 / 知识产权」进入现网站对应栏目

电脑和手机怎么看

豆包 About 缩成手机宽度后会跳过开场、变成静态。我们这版电脑和手机都播 3D。

  • 电脑：窗口拉满，打开或刷新即可。
  • 手机构图：把浏览器窗口拉窄到手机宽度，再刷新（只缩不刷新仍是电脑那一版）。也可以用开发者工具里的手机模式后刷新。

为什么用实时 3D，而不是豆包那种开场视频

豆包 About 的开场是预渲染成片，播完再切到网页。我们改成网页里直接播 GLB：

  • 同一套人物以后可以单独拿出来，做悬停、对话框、点头等交互，不用每改一次就重渲一条视频。
  • 开场要加动作（张臂、扑向镜头），往模型里加一段 animation 即可，前端按名字播放。

这一版占位模目前只有挥手。正式模会补齐张臂、扑镜，并换成你的动漫形象。

还没做、不必担心

  • 正式 3D 形象仍在出模。
  • 手机单独构图、嵌入仿宋 / Times 字体，下一轮。
  • 线上 yaojunxd.com 首页一行都没改。
请先看气质和节奏：颜色、卡片角度和模糊、标题对焦、3D 出场是否顺。回复里直接标「改这里」即可。样板你点头之前，我们不会嵌进正式站。
